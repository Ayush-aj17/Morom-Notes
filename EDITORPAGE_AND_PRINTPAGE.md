# EditorPage & PrintPage - Complete Documentation

## Overview

You now have two complementary pages for viewing and exporting notes:

1. **EditorPage** (`/editor/:id`) - Interactive editing + PDF export
2. **PrintPage** (`/print?id=:id`) - Print-optimized view + browser print

---

## EditorPage (`/editor/:id`)

### Purpose
Main interface for reading, editing, and exporting notes with AI chat integration.

### Layout
```
┌─────────────────────────────────────────────────────────┐
│  Header (Title + Actions)                               │
├──────────────────────────┬──────────────────────────────┤
│                          │                               │
│   Content Area           │    StudyBuddy Chat Sidebar   │
│  (Edit/Preview)          │   (AI Guidance)               │
│                          │                               │
└──────────────────────────┴──────────────────────────────┘
```

### Actions Available

| Button | Function | Shortcut |
|--------|----------|----------|
| ⭐ | Toggle favorite status | - |
| ✏️ Edit | Enter edit mode | - |
| 👁️ Preview | Exit edit mode | - |
| 💾 Save | Save changes to database | Ctrl+S (manual click) |
| 🖨️ Print | Open PrintPage | - |
| 📥 PDF | Download as PDF | - |
| ✕ | Go back to dashboard | - |

### Edit Mode
- **Text Input**: Raw markdown textarea
- **Live Preview**: Disabled while editing
- **Save**: Updates `/api/notes/{id}` PUT
- **Markdown Support**: Full markdown with math equations

### Preview Mode
- **Rendered Display**: Beautiful markdown rendering
- **ReactMarkdown**: Converts markdown to HTML
- **Math Support**: KaTeX for equations
- **Chat Available**: StudyBuddy sidebar active

### PDF Export
- **Captures**: The preview pane exactly as shown
- **Quality**: 2x resolution for clarity
- **Pages**: Handles multi-page content automatically
- **Format**: PNG embedded in PDF

### Title Renaming
- Click ✏️ next to title
- Inline input appears
- Click Save or press Enter
- Updates `/api/notes/{id}/rename` PUT

### Favorite Toggle
- Click ⭐ icon
- Updates `/api/notes/{id}/favorite` PUT
- Star fills/empties based on status

### StudyBuddy Integration
- **Right Sidebar**: Always visible in preview mode
- **Chat Input**: Type questions or requests
- **AI Suggestions**: Get editing hints
- **Apply Changes**: Click to update note
- **Real-time Sync**: Note updates reflected in editor

## PrintPage (`/print?id=:id`)

### Purpose
Printer-friendly view of notes optimized for printing and browser print functionality.

### Layout
```
┌──────────────────────────┐
│ Toolbar (Print button)   │ ← Hidden when printing
├──────────────────────────┤
│                          │
│  Cover Page              │ (Page 1)
│  - Title                 │
│  - Metadata              │
│  - Generated info        │
│                          │
├──────────────────────────┤
│                          │
│  Content Page            │ (Page 2+)
│  - Header with title     │
│  - Full markdown content │
│  - Rendered properly     │
│  - Footer with date      │
│                          │
└──────────────────────────┘
```

### How to Access
- **From EditorPage**: Click the "Print" button (purple)
- **Direct URL**: `/print?id=10` (where 10 is note ID)

### Toolbar (Not Printed)
- **Print Button**: Opens browser print dialog
- **Dashboard Button**: Returns to dashboard

### Cover Page (Page 1)
Displays:
- Note title (large, centered)
- Source type (if available)
- Creation date
- Subject (if available)
- Footer: "Generated by Morom Notes"

### Content Pages (Page 2+)
Displays:
- Page header with note title
- Full markdown content (rendered)
- Page footer with "Morom Notes • Date"
- Automatic page breaks for long content

### Print Features
- **CSS-optimized**: Special @media print styles
- **Page Breaks**: Smart breaks to avoid orphaned content
- **Colors**: Preserved in print (exact colors)
- **Images**: Handled gracefully
- **Tables**: Full-width, formatted for print
- **Code Blocks**: Handled with proper formatting

### Browser Print Dialog
After clicking "Print", you can:
- **Save as PDF**: Print → Save as PDF (best option)
- **Print to Printer**: Direct printer output
- **Edit Settings**: Page margins, headers/footers
- **Print Range**: Select specific pages
- **Orientation**: Portrait or landscape

## Workflow Examples

### Scenario 1: Edit and Export PDF
1. Open note in EditorPage (`/editor/10`)
2. Click "Edit" → Make changes
3. Click "Save" → Changes saved
4. Click "PDF" → Downloads PDF

### Scenario 2: Edit with AI Guidance
1. Open note in EditorPage
2. Use StudyBuddy sidebar to get suggestions
3. Click "Apply" on suggestions
4. Content updates automatically

### Scenario 3: Print-friendly Version
1. Open note in EditorPage
2. Click "Print" button → Goes to PrintPage
3. Enjoy clean, printer-optimized view
4. Click browser "Print" → Save as PDF or print

### Scenario 4: Print Multiple Notes
1. Open Note 1 in EditorPage
2. Click "Print" → See PrintPage
3. Use browser Print function
4. Repeat for other notes as needed

## API Endpoints

### EditorPage Uses
- `GET /api/notes/{id}` - Load note
- `PUT /api/notes/{id}` - Save content
- `PUT /api/notes/{id}/rename` - Rename title
- `PUT /api/notes/{id}/favorite` - Toggle favorite
- `POST /api/notes/{id}/study-buddy` - Chat with AI
- `POST /api/notes/{id}/study-buddy/apply` - Apply AI changes

### PrintPage Uses
- `GET /api/notes/{id}` - Load note only

## Performance Tips

### For EditorPage
- **Large Notes**: Chat updates might be slow
- **Solution**: Edit in small chunks, save frequently

### For PrintPage
- **Large Notes**: Page rendering takes time
- **Solution**: Use browser's print dialog for faster processing

### PDF Export
- **Quality vs Speed**: Higher scale = bigger file
- **Default**: scale 2 (good balance)
- **Modify**: Change line 144 in EditorPage.jsx

## Error Handling

### EditorPage Errors
- **"Failed to load note"** → Check note ID, access permissions
- **"Error saving"** → Check network, verify API
- **"PDF export failed"** → Check console, try simpler note

### PrintPage Errors
- **"No note ID provided"** → Must have `?id=` in URL
- **"Failed to load note"** → Check note ID validity
- **Can't print** → Try different browser

## Troubleshooting

### Common Issues

**Issue**: "PrintPage not found" error
**Solution**: Make sure PrintPage.jsx exists and is imported in App.jsx

**Issue**: Print page looks wrong
**Solution**: Zoom browser to 100% before printing (usually in Ctrl+P dialog)

**Issue**: PDF is huge file size
**Solution**: Lower scale in EditorPage.jsx or use PrintPage's browser print → PDF

**Issue**: Math equations not rendering
**Solution**: Ensure remark-math and rehype-katex are in dependencies

**Issue**: Markdown formatting not showing
**Solution**: Use proper markdown syntax; check in preview mode first
